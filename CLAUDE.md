# AstroSphere

## Ringkasan konteks

AstroSphere adalah platform web edukasi astronomi berbahasa Indonesia untuk siswa, guru, dan admin konten. Fitur utama adalah visualisasi 3D tata surya real-time di browser melalui WebGL, dengan pengalaman jelajah planet, titik minat (POI), fenomena astronoms, kelas, tur terpandu, progres, kuis, dan pengelolaan konten.

Platform ditujukan terutama bagi lingkungan sekolah Indonesia, termasuk laptop menengah dan koneksi internet lambat. Target performa minimal adalah 30 FPS. Server hanya menyajikan data dan aset; seluruh render serta interaksi 3D berjalan di browser.

## Stack teknologi

- Vite
- React 18
- TypeScript dengan `strict`
- three
- @react-three/fiber
- @react-three/drei
- zustand untuk state
- Tailwind CSS untuk UI
- react-router untuk navigasi
- Supabase untuk Auth, PostgreSQL, dan Storage pada fase berikutnya
- Data fase awal dari berkas JSON lokal melalui lapisan repository yang dapat diganti ke Supabase tanpa mengubah komponen
- Deploy ke Vercel
- Vitest untuk unit dan integration test
- Playwright untuk end-to-end test

## Aturan pengembangan

1. Jangan menambah kode aplikasi sebelum arah produk dan struktur fase awal disetujui.
2. Seluruh teks antarmuka harus disimpan dalam satu berkas string agar mudah dilokalkan atau diubah.
3. Implementasi harus modular, dengan komponen yang terpisah dari sumber data.
4. Lapisan repository harus abstrak sehingga backend JSON lokal dapat diganti dengan Supabase tanpa perubahan komponen UI.
5. Tetapkan komponen 3D hanya sebagai klien browser; server hanya mengirim data dan aset.
6. Gunakan navigasi keyboard penuh, teks alternatif, fokus terlihat, dan kontras minimal WCAG AA.
7. Sediakan opsi "Kurangi animasi" dan hormati `prefers-reduced-motion`.
8. Aset planet dimuat secara bertahap per planet, dengan lazy loading.
9. Gunakan kompresi tekstur dan model serta sediakan tiga tingkat kualitas: tinggi, sedang, dan rendah.
10. Jaga target performa minimal 30 FPS pada perangkat menengah.
11. Sediakan mode performa rendah yang dapat mengurangi detail visual, tekstur, jumlah partikel, dan gerak.
12. Konten faktual tidak boleh menggunakan angka yang belum dapat diverifikasi.
13. Setiap fakta di UI harus memiliki field sumber.
14. Data yang diragukan harus ditandai `perlu verifikasi`.
15. Gunakan tekstur dan model berlisensi terbuka atau domain publik.
16. Catat lisensi dan atribusi untuk setiap aset.
17. Jika aset berlisensi terbuka belum tersedia, gunakan fallback prosedural seperti shader atau noise agar aplikasi tetap berjalan.
18. Berikan komentar singkat pada bagian matematika 3D yang tidak langsung jelas.
19. Jangan membuat keputusan UI, konten, atau arsitektur yang bertentangan dengan dokumentasi ini tanpa mencatatnya pada bagian Keputusan.

## Arah desain

AstroSphere adalah pengalaman 3D-first. Kanvas WebGL adalah antarmuka utama, sedangkan UI 2D hanya menjadi lapisan tipis di atasnya.

### Visual dan suasana

- Gunakan panel kaca semi-transparan dengan gaya instrumen planetarium atau observatorium.
- Gunakan latar ruang angkasa gelap dengan kontras tinggi.
- Sesuaikan aksen warna dengan objek yang difokuskan: Mars memakai warna karat-oranye, Jupiter memakai krem-oranye, dan planet lain memakai aksen masing-masing.
- Hindari tampilan template generik.
- Bangun identitas visual konsisten melalui design tokens untuk warna, spasi, radius, bayangan, dan status.
- Pastikan tipografi tetap terbaca pada layar laptop menengah dan koneksi lambat.

### Tipografi

- Gunakan satu font display geometris untuk judul.
- Gunakan satu sans serif yang sangat terbaca untuk isi.
- Gunakan gaya tabular untuk angka dan dimensi agar mudah dibaca.
- Hindari memuat terlalu banyak keluarga font agar aset font tetap ringan.

### Gerak dan kamera

- Pergerakan kamera menggunakan easing sinematik, bukan lompatan.
- Zoom, rotasi, pan, dan perpindahan antarobjek harus terasa mulus.
- Semua gerakan harus memiliki versi dikurangi untuk preferensi aksesibilitas.
- Hormati `prefers-reduced-motion`.

### Aksesibilitas dan responsivitas

- UI lapisan harus dapat digunakan sepenuhnya dari keyboard.
- Berikan label dan teks alternatif yang bermakna untuk kontrol serta objek interaktif.
- Pertahankan kontras WCAG AA pada panel, teks, ikon, dan kontrol.
- Tata letak harus tetap dapat digunakan pada laptop sekolah dan ukuran layar yang terbatas.

### Aset dan sumber konten

- Contoh sumber terbuka yang perlu dipertimbangkan adalah NASA dan lembaga ilmiah/data terbuka lain yang dapat diverifikasi.
- Simpan atribusi lisensi bersama metadata aset.
- Pastikan setiap fakta memiliki sumber yang dapat ditelusuri.
- Jika metadata belum lengkap atau nilainya diragukan, tandai dengan `perlu verifikasi`.

## Perintah proyek

- `npm run dev` - menjalankan aplikasi Vite secara lokal.
- `npm run build` - memeriksa tipe TypeScript dan membuat build produksi.
- `npm run build:seed` - menghasilkan berkas seed SQL Supabase dari data JSON MVP.
- `npm run optimize:textures` - mengompres tekstur mentah menjadi 3 resolusi WebP (high/mid/low).
- `npm run optimize:models` - mengoptimasi model glTF/GLB menggunakan gltf-transform.
- `npm run import:nasa` - mengimpor data ilmiah NASA secara offline ke JSON lokal dan seed.
- `npm run test` - menjalankan unit test dengan Vitest.
- `npm run lint` - menjalankan ESLint pada seluruh source.
- `npm run format` - memformat berkas dengan Prettier.
- `npm run format:check` - memeriksa format berkas.
- `npm run e2e` - menjalankan pengujian Playwright.
